YouTube API-sleutel instellen

Om video's op YouTube te kunnen zoeken heeft Musicwall een gratis YouTube API-sleutel nodig. Vraag deze eenmalig aan via Google en plak hem hieronder — dit scherm verschijnt niet meer zodra dat gelukt is.

  1. Ga naar console.cloud.google.com en log in met een Google-account
  2. Maak een nieuw project aan via Project selecteren → Nieuw project
  3. Ga naar API's en services → Bibliotheek
  4. Zoek op YouTube Data API v3 en klik op Inschakelen
  5. Ga naar API's en services → Inloggegevens
  6. Klik op Inloggegevens maken → API-sleutel
  7. Kopieer de sleutel die verschijnt
