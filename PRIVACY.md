# Privacybeleid — Musicwall

Musicwall is een lokale desktopapplicatie. De app:

- Slaat alle gegevens (walls, concertervaringen, video's, foto's) uitsluitend lokaal op, in een SQLite-database op uw eigen computer
- Verzendt geen persoonlijke gegevens naar de ontwikkelaar of naar derden
- Maakt alleen verbinding met YouTube (YouTube Data API v3) om, met uw eigen API-sleutel, video's en playlists op te zoeken en af te spelen — dit gebeurt rechtstreeks tussen uw computer en YouTube/Google
- Bevat geen accounts, geen tracking en geen reclame

Voor vragen: araap@hotmail.com

# Privacy Policy — Musicwall (English)

Musicwall is a local desktop application. The app:

- Stores all data (walls, concert experiences, videos, photos) exclusively on your own computer, in a local SQLite database
- Does not send any personal data to the developer or to third parties
- Only connects to YouTube (YouTube Data API v3) to search and play videos and playlists, using your own API key — this happens directly between your computer and YouTube/Google
- Contains no accounts, no tracking, and no advertising

For questions: araap@hotmail.com
