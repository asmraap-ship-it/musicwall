# Privacybeleid — Musicwall

**Laatst bijgewerkt:** 6 juli 2026

Musicwall is een lokale desktopapplicatie. De app:

- Slaat alle gegevens (walls, concertervaringen, video's, foto's) uitsluitend
  lokaal op, in een SQLite-database op uw eigen computer
- Verzendt geen persoonlijke gegevens naar de ontwikkelaar of naar derden
- Maakt alleen verbinding met YouTube (YouTube Data API v3) om, met uw eigen
  API-sleutel, video's en playlists op te zoeken en af te spelen — dit
  gebeurt rechtstreeks tussen uw computer en YouTube/Google
- Bevat geen accounts, geen tracking en geen reclame

### Uw controle over uw gegevens

Omdat alle gegevens uitsluitend lokaal worden opgeslagen, heeft u volledige
controle: verwijder de lokale database of verwijder de applicatie om alle
opgeslagen gegevens (walls, concertervaringen, video's, foto's en uw eigen
YouTube API-sleutel) definitief te wissen. Er bestaat geen externe kopie.

### Uw YouTube API-sleutel

Uw eigen YouTube Data API v3-sleutel wordt lokaal opgeslagen op uw computer
en nooit gedeeld met de ontwikkelaar of derden. Gebruik van deze sleutel
valt onder [YouTube's API Services Terms of Service](https://developers.google.com/youtube/terms/api-services-terms-of-service)
en het [Google Privacybeleid](https://policies.google.com/privacy).

# Privacy Policy — Musicwall (English)

**Last updated:** July 6, 2026

Musicwall is a local desktop application. The app:

- Stores all data (walls, concert experiences, videos, photos) exclusively
  on your own computer, in a local SQLite database
- Does not send any personal data to the developer or to third parties
- Only connects to YouTube (YouTube Data API v3) to search and play videos
  and playlists, using your own API key — this happens directly between
  your computer and YouTube/Google
- Contains no accounts, no tracking, and no advertising

### Your control over your data

Because all data is stored exclusively on your own device, you have full
control: deleting the local database or the application permanently erases
all stored data (walls, concert experiences, videos, photos, and your own
YouTube API key). No external copy exists.

### Your YouTube API key

Your own YouTube Data API v3 key is stored locally on your device and is
never shared with the developer or any third party. Use of this key is
subject to [YouTube's API Services Terms of Service](https://developers.google.com/youtube/terms/api-services-terms-of-service)
and the [Google Privacy Policy](https://policies.google.com/privacy).
