YouTube API-sleutel instellen

Om video's op YouTube te kunnen zoeken heeft Musicwall een gratis YouTube API-sleutel nodig. Vraag deze eenmalig aan via Google en plak hem hieronder — dit scherm verschijnt niet meer zodra dat gelukt is.

Schakel de YouTube Data API in

Log in bij Google en schakel de YouTube Data API in voor uw project — dat is nodig om straks op YouTube te kunnen zoeken vanuit Musicwall.

Maak een API-sleutel aan

Klik op + Create credentials → API key om een nieuwe sleutel aan te maken.
